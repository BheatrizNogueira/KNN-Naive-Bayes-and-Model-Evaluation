# KNN-Naive-Bayes-and-Model-Evaluation
# Machine Learning Fundamentals

## 📖 About

This repository contains a collection of Machine Learning projects developed in Python as part of my studies. The notebooks explore fundamental supervised learning algorithms and model evaluation techniques using real datasets and the Scikit-learn library.

## 📂 Projects

### 📈 Regression
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Regression model training
- Prediction and performance evaluation

### 👥 K-Nearest Neighbors (KNN)
- Data preprocessing
- Feature selection
- KNN model implementation
- Classification and prediction

### 📊 Naive Bayes
- Data preprocessing
- Probabilistic classification
- Model training
- Prediction and evaluation

### 📉 Model Evaluation
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC Curve and AUC

## 🛠️ Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## 🎯 Objectives

- Learn the fundamentals of Machine Learning.
- Implement supervised learning algorithms.
- Compare different models.
- Evaluate model performance using industry-standard metrics.
- Build a practical Machine Learning portfolio.

## ▶️ How to Run

1. Clone this repository.
2. Open the notebooks in Google Colab or Jupyter Notebook.
3. Install the required libraries if necessary.
4. Run all notebook cells.
